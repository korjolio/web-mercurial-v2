Formatos (ver `posts.js`): portada (foto a sangre), dato (azul, cifra grande), pregunta (fondo claro), split (foto + bloque blanco) y carrusel. El calendario los alterna para que el feed no se vea como una sola plantilla.

Ritmo sugerido: lunes, martes, jueves y viernes, alternando producto y formato.

Reglas que siguen todos los textos: solo afirmaciones publicadas en mercurial.cl (o en las piezas de Ads aprobadas), sin cifras ni coberturas nuevas, y sin el N° de registro CMF. Si cambias un caption, contrástalo con la landing del producto.

Instagram no deja links en los captions: el link va en la bio o en una historia con sticker de enlace. Por eso el CTA repite la URL y suma el WhatsApp.

## Regenerar las imágenes

```bash
npm i --no-save playwright && npx playwright install chromium
node instagram/render.js                  # todos → instagram/2026-11/
node instagram/render.js salida/ 07-mascotas-planes   # uno solo (o un carrusel completo)
```

Textos en `posts.js`, diseño en `plantilla.html`. Exporta JPG (la Content Publishing API de Instagram solo acepta JPEG). El script avisa con ⚠ DESBORDE si un texto no cabe.
