## Fotos

Las de `fotos/` vienen de Pexels (licencia libre para uso comercial, sin atribución obligatoria); el número del archivo es el ID: `https://www.pexels.com/photo/<ID>/`. La de mascotas (`06`) es `src/img/mascota.jpeg`, la misma de la landing.

## Regenerar las imágenes

```bash
npm i --no-save playwright && npx playwright install chromium
node instagram/render.js                  # todos → instagram/2026-11/
node instagram/render.js salida/ 07-mascotas-planes   # uno solo
```

Textos en `posts.js`, diseño en `plantilla.html`. El script avisa con ⚠ DESBORDE si un texto no cabe.
